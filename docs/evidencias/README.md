# Evidências reais

Salve nesta pasta apenas capturas e registros obtidos durante a execução. Não edite imagens para aparentar resultados diferentes.

## Checklist de captura

1. Tela inicial com lista e, se aplicável, estado vazio.
2. Formulário de registro preenchido, sem dados pessoais reais.
3. Detalhes, status atual e histórico.
4. Repositório GitHub e sequência de commits.
5. Pull request com descrição e revisão.
6. Saída real de `npm test`, `npm run lint` e `npm run build`.
7. Execução verde do workflow CI.
8. Aplicação publicada e smoke test real.

Anote em `registro.md` a data, o ambiente, o commit, o que foi testado e o resultado. Não inclua chaves, e-mails pessoais ou localização sensível nas capturas.
